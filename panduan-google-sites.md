# Panduan Implementasi E-Portofolio PPG Prajabatan di Google Sites

## 📋 Overview
Template ini telah dirancang khusus untuk memenuhi standar e-portofolio PPG Prajabatan sesuai pedoman UKMPPG. Template HTML dapat diimplementasikan di Google Sites dengan mengikuti langkah-langkah berikut.

## 🚀 Langkah 1: Persiapan Google Sites

### 1.1 Buat Google Sites Baru
1. Buka [sites.google.com](https://sites.google.com)
2. Klik **"+ Buat"** atau **"Blank"**
3. Beri nama situs: "E-Portofolio PPG Prajabatan - [Nama Anda]"
4. Pilih tema yang profesional dan bersih

### 1.2 Pengaturan Dasar
- **Judul Situs**: E-Portofolio PPG Prajabatan
- **Alamat Web**: Pilih alamat yang mudah diingat
- **Tema**: Pilih tema dengan warna profesional (biru/ungu)

## 🎨 Langkah 2: Implementasi Struktur Halaman

### 2.1 Halaman Utama (Home)
1. **Header Section**
   - Tambahkan judul: "E-Portofolio PPG Prajabatan"
   - Subjudul: "Dokumentasi Perjalanan Profesional Guru"
   - Gunakan banner image yang profesional

2. **Profil Section**
   - Tambahkan foto profil (format persegi)
   - Informasi personal:
     - Nama Lengkap
     - NIM
     - Program Studi
     - Universitas
     - Angkatan
     - Email

### 2.2 Buat Sub-Halaman untuk Setiap Komponen

#### 📄 Halaman: Penelitian dan Publikasi
- **Judul**: "1. Penelitian dan Publikasi"
- **Subsection**:
  - Jurnal Internasional (Skor: 3)
  - Jurnal Nasional S1/S2 (Skor: 2.5)
  - Laporan Penelitian (Skor: 1)
- **Format**: Gunakan Cards/Columns untuk setiap jenis publikasi

#### 📄 Halaman: Refleksi Diri
- **Judul**: "2. Refleksi Diri"
- **Subsection**:
  - Refleksi Pengembangan Diri (Skor: 0.5)
  - Refleksi Penelitian (Skor: 0.5)
  - Refleksi Inovasi (Skor: 0.5)
- **Format**: Text blocks dengan space untuk upload dokumen

#### 📄 Halaman: Pencarian Informasi Baru
- **Judul**: "3. Pencarian Informasi Baru"
- **Subsection**:
  - Diklat/Pelatihan (Skor: 1-15)
  - Seminar/Konferensi (Skor: 0.1-1)
  - Paket Kegiatan Guru (Skor: 0.35/paket)
- **Format**: Table untuk tracking jam kegiatan

#### 📄 Halaman: Inovasi Baru
- **Judul**: "4. Inovasi Baru dalam Pendidikan"
- **Subsection**:
  - Buku Teks (Skor: 0.5-6)
  - Modul/LKPD (Skor: 0.5-2)
  - Alat Peraga (Skor: 1-2)
  - Karya Teknologi (Skor: 2-4)
- **Format**: Image gallery untuk dokumentasi

#### 📄 Halaman: Prestasi (Opsional)
- **Judul**: "5. Prestasi"
- **Subsection**:
  - Kompetisi Internasional (Skor: 2-3)
  - Kompetisi Nasional (Skor: 1-2)
  - Kompetisi Regional/Provinsi (Skor: 0.3-1)
- **Format**: Achievement badges dengan link bukti

#### 📄 Halaman: Pengabdian (Opsional)
- **Judul**: "6. Pengabdian pada Masyarakat"
- **Subsection**:
  - Kepanitiaan Internasional (Skor: 2-3)
  - Kepanitiaan Nasional (Skor: 1-2)
  - Kepanitiaan Daerah (Skor: 0.2-1)
- **Format**: Timeline untuk kegiatan pengabdian

## 🔧 Langkah 3: Konfigurasi Navigasi

### 3.1 Menu Navigation
1. Buka **Pages** di sidebar
2. Atur urutan halaman:
   - Home
   - Penelitian dan Publikasi
   - Refleksi Diri
   - Pencarian Informasi Baru
   - Inovasi Baru
   - Prestasi
   - Pengabdian
   - Kontak

### 3.2 Header Menu
- Tambahkan horizontal navigation menu
- Gunakan icon untuk setiap menu item

## 📁 Langkah 4: Upload dan Management Dokumen

### 4.1 Google Drive Integration
1. Buat folder structure di Google Drive:
   ```
   E-Portofolio PPG/
   ├── 1_Penelitian/
   ├── 2_Refleksi/
   ├── 3_Pencarian_Informasi/
   ├── 4_Inovasi/
   ├── 5_Prestasi/
   ├── 6_Pengabdian/
   └── Dokumen_Pendukung/
   ```

### 4.2 Format File yang Diperbolehkan
- **PDF**: Untuk dokumen teks, laporan, sertifikat
- **JPEG/PNG**: Untuk foto, screenshot, dokumentasi
- **URL Link**: Untuk video YouTube, Google Drive, publikasi online

### 4.3 Cara Upload di Google Sites
1. Klik **Insert** → **Drive**
2. Pilih file dari Google Drive
3. Atur display options:
   - **Icon**: Untuk file PDF
   - **Thumbnail**: Untuk gambar
   - **Link**: Untuk eksternal URL

## 🎯 Langkah 5: Tips dan Best Practices

### 5.1 Design Tips
- **Color Scheme**: Gunakan 2-3 warna utama (biru profesional)
- **Typography**: Font yang mudah dibaca (Arial, Roboto)
- **Layout**: Grid layout untuk organization
- **White Space**: Cukup whitespace untuk readability

### 5.2 Content Guidelines
- **Narasi Deskripsi**: Tulis deskripsi 2-3 paragraf untuk setiap komponen
- **Bukti Fisik**: Pastikan semua bukti valid dan dapat diverifikasi
- **Consistency**: Gunakan format konsisten untuk semua section

### 5.3 SEO dan Sharing
- **Meta Description**: Tambahkan deskripsi situs
- **Share Settings**: Atur visibility ke "Public on the web"
- **Custom Domain**: Jika perlu, setup custom domain

## 📊 Langkah 6: Progress Tracking

### 6.1 Status Indicators
Gunakan visual indicators untuk setiap komponen:
- ✅ **Complete**: Bukti sudah diupload
- ⏳ **In Progress**: Sedang dikerjakan
- ❌ **Not Started**: Belum dimulai

### 6.2 Score Calculator
Buat section khusus untuk tracking:
- Total skor per komponen
- Progress percentage
- Status validation

## 🔗 Langkah 7: Integration dengan UKMPPG

### 7.1 Link ke Portal UKMPPG
- Tambahkan link ke [ukin.ukmppg.id](https://ukin.ukmppg.id)
- Berikan instruksi login dan submission

### 7.2 Export Options
- **PDF Export**: Gunakan fitur print to PDF
- **Share Link**: Generate shareable link
- **Backup**: Regular backup ke Google Drive

## 📱 Langkah 8: Mobile Optimization

### 8.1 Responsive Design
- Test di mobile devices
- Ensure navigation works on touch screens
- Optimize image sizes for mobile

### 8.2 Loading Speed
- Compress images
- Minimize external links
- Use Google Sites built-in optimization

## 🔄 Maintenance Schedule

### Weekly
- Check broken links
- Update progress status
- Backup content

### Monthly
- Review content accuracy
- Update achievements
- Optimize performance

## 🆘 Troubleshooting

### Common Issues
1. **File Upload Failed**: Check file size limit (100MB)
2. **Link Not Working**: Verify sharing permissions
3. **Layout Broken**: Clear browser cache
4. **Access Denied**: Check site sharing settings
